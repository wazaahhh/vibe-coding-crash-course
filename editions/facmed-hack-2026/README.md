# FacMed Hack edition — Crash Course #2

*Vibe Coding for Scientists* re-cut as **Crash Course #2 of FacMed Hack #1 — Digital
Phenotyping of Mental Health** (UNIGE Faculty of Medicine; module B2 of the course proposal to the
Lemanic Neuroscience Doctoral School). Thursday 22 October 2026, 17:00–19:00, **on Zoom**.
Audience: PhD students, postdocs and PIs, mostly neuroscience, a third with some Python, most new
to git.

Three objectives:

1. **Imagine**: where AI agents come from, what they already do in research, and your place
   (contribution, career, purpose) in a bright, sustainable and safe future with them.
2. **Understand**: how vibe coding works: fast and slow, try and fail, git run by the agent for
   you, working collectively.
3. **Prepare**: the hack's status, and how it runs with or without your own tools; the HPE /
   NVIDIA environment is open to every team.

modules 01–04.

**Live quiz.** Ten questions (the second, "opening", free text; "dst" and "missing" with a correct answer) run on a small app of our own (`apps/live-quiz` in the corp repo,
Cloudflare Pages + D1, live at https://facmed-quiz.pages.dev): participants vote anonymously
with a PIN given in the Zoom chat (QR code + link on the slides, generated by `build.sh` from
`quiz_url.txt` into `assets/quiz_qr.svg`). Run it from `/admin` (admin token) and share the
presenter view `/present?key=…`, whose QR code carries the PIN. `zoom_polls.md` is the fallback.

**Quiz PIN on the slides.** Build with `QUIZ_PIN=1234 ./build.sh --pdf`: every quiz call-out shows
the PIN and the QR code carries it (`/?pin=…`). Without `QUIZ_PIN` the slides say the PIN is in the
Zoom chat. The PIN build rewrites `assets/quiz_qr.svg`: rebuild without `QUIZ_PIN` before committing.

**Images.** Diagrams (perceptron, neural network, Transformer, LLM and VLM schematics, frontier
systems) are drawn for this deck as SVG in `assets/`. `env_chat.png`, `env_completion.svg` and
`env_agents.svg` are faithful mock-ups of a chat assistant, of code completion in VS Code, and of an
app running several coding agents in parallel: replace them with real screenshots if preferred
(`env_agent.png`, VS Code with one agent, is no longer on a slide). `hackathon_2019_2025.jpg` comes
from the Hack the Hackathon 6 talk (agentic-hacks, `talks/2026-10-hack-the-hackathon`).
`room4_3d.png` (4by4k / gen_social 3-D reconstruction, stick figures only) and
`asd_wavelet_method.png` (method schematic on a synthetic signal) come from Thomas's own projects:
unpublished, keep the branch private until checked.
